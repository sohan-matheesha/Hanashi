# Hanashi (話し) – Japanese Language Practice Platform

Hanashi is a web-based Japanese language learning and practice platform designed for beginner learners, especially students who want to improve their Japanese reading, vocabulary, grammar, cultural understanding, and communication skills.

The platform provides structured learning content, quizzes, cultural learning materials, AI tutor support, and conversation-based practice features. Hanashi is developed as a final year project to support practical Japanese language learning through a simple and interactive digital platform.

## Main Features

- User registration and login
- Role-based access for students, teachers, and administrators
- Student dashboard with learning sections
- Structured Japanese lessons
- Hiragana and Katakana learning content
- Vocabulary and grammar learning sections
- Quiz-based learning activities
- AI tutor support for Japanese practice
- Conversation practice section
- Cultural learning hub
- Admin dashboard for user and system management
- Teacher dashboard for managing learning content

---

## User Roles

### Student

Students can access lessons, quizzes, cultural content, AI tutor support, and conversation practice activities.

### Teacher

Teachers can manage learning materials and support students through teaching-related dashboard features.

### Admin

Administrators can manage users, roles, system content, and platform-level controls.
